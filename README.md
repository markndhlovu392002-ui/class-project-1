# StudyHub

StudyHub is a proposed academic resource platform that helps students find study materials for their courses in one place.

The system is designed to make it easier for students to find books, lecture slides, past papers and other useful study resources that have been recommended by lecturers.

## Problem

Students often have to search for study materials in different places such as WhatsApp groups, emails, shared drives and websites. This can make it difficult to find the right resources and know which ones can be trusted.

StudyHub aims to solve this problem by providing a central place where students can find course-related study materials.

## Features

* View recommended books
* View lecture slides
* View past examination papers
* View verified resources
* Search for resources
* Filter resources by type
* Save useful resources

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

The project can also be run using Live Server in Visual Studio Code.

## How It Works

1. Select a course.
2. View the available resources.
3. Search or filter the resources.
4. Select a resource to view more information.
5. Use the resource for studying.
